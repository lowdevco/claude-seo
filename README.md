# Claude SEO

<p>
This is a Claude Code skill for comprehensive website analysis, audits, technical SEO, and AI search optimization. It analyzes your target site, evaluates search signals, and produces an actionable, prioritized roadmap directly inside Claude.
</p>

<p>
Add this skill to Claude, enter <code>/seo</code> followed by a command and URL, and you're ready to audit.
</p>

### Quick Start (One Command)

```bash
/seo audit https://example.com
```

---

### Commands

| Command | Description |
| :--- | :--- |
| <code>/seo audit &lt;url&gt;</code> | Full website audit with parallel specialist agents |
| <code>/seo page &lt;url&gt;</code> | Deep single-page analysis |
| <code>/seo technical &lt;url&gt;</code> | Technical SEO audit across crawlability, security, and performance |
| <code>/seo content &lt;url&gt;</code> | E-E-A-T and content quality assessment |
| <code>/seo content-brief &lt;topic&gt;</code> | Detailed SEO content brief with keywords, outline, and internal links |
| <code>/seo schema &lt;url&gt;</code> | Schema.org structured data validation and generation |
| <code>/seo sitemap &lt;url&gt;</code> | XML sitemap analysis and generation |
| <code>/seo images &lt;url&gt;</code> | Image SEO analysis and optimization |
| <code>/seo geo &lt;url&gt;</code> | Generative Engine Optimization (AI Overviews, ChatGPT, Perplexity) |
| <code>/seo local &lt;url&gt;</code> | Local SEO (Google Business Profile, citations, reviews) |
| <code>/seo maps [command]</code> | Maps intelligence (geo-grid, GBP audit, competitor radius) |
| <code>/seo agentic &lt;url&gt;</code> | AI agent readiness checks (llms.txt, WebMCP, Markdown) |
| <code>/seo cluster &lt;keyword&gt;</code> | Semantic topic clustering and content architecture |
| <code>/seo sxo &lt;url&gt;</code> | Search Experience Optimization analysis |
| <code>/seo drift &lt;url&gt;</code> | SEO drift monitoring and baseline comparisons |
| <code>/seo ecommerce &lt;url&gt;</code> | E-commerce SEO: product schema, marketplace intelligence |
| <code>/seo hreflang [url]</code> | International SEO, hreflang audit, and cultural profiles |
| <code>/seo plan &lt;type&gt;</code> | Strategic planning by industry |
| <code>/seo programmatic &lt;url&gt;</code> | Programmatic SEO analysis and safeguards |
| <code>/seo competitor-pages &lt;url&gt;</code> | Competitor comparison page generation |
| <code>/seo flow [stage]</code> | FLOW framework prompts (Find, Leverage, Optimize, Win, Local) |
| <code>/seo backlinks &lt;url&gt;</code> | Backlink profile analysis and referring domain audit |

---

### Features

<p>
<b>Technical SEO</b>: Crawlability, indexability, redirects, XML sitemaps, robots.txt, Core Web Vitals (INP), and hreflang.<br />
<b>Content & E-E-A-T</b>: Content depth, readability, semantic keyword clustering, and structured content briefs.<br />
<b>Structured Data</b>: Automated Schema.org JSON-LD generation and error detection.<br />
<b>AI Search & GEO</b>: Citability audits for AI Overviews, Perplexity, Gemini, and ChatGPT.<br />
<b>Local & Commerce</b>: Google Business Profile optimization, local citation signals, and product markup.
</p>
